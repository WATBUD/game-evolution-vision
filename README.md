# Game Evolution

Windows 桌面工具，可錄製鍵盤按下／放開與時間間隔，將腳本儲存為 JSON，並只在選定的遊戲或瀏覽器視窗中播放。

## 功能

- 從目前可見視窗清單選擇目標程式
- 可一次多選匯入 PNG/JPG/BMP/WebP 圖片，逐張預覽並偵測指定視窗內是否出現任一圖片
- 支援 Windows 內建繁體中文 OCR，可用文字關鍵字偵測畫面並忽略大小寫、空白與全／半形差異
- 支援多目标文字列表，每项文字可独立设置相似度与提示音次数
- 偵測類型預設為 `ALL`（圖片＋文字同步偵測），也可由下拉選單改成單一圖片或文字偵測；同一輪共用一次視窗擷取並分別計算命中、提示音與冷卻
- 圖片陣列與偵測／提示音設定會儲存為本機專案，下次啟動自動還原
- 內建桌面框選擷取，可直接製作圖片範本並在介面中預覽
- 框選圖片會自動儲存到程式旁的 `captures` 資料夾，匯入圖片時也會預設開啟此位置
- 支援單次偵測與可調間隔的持續監看，顯示相似度、座標及命中像素數
- 圖片或文字達到門檻時播放 Game Evolution 專用單聲鈴音；偵測與腳本繼續執行，音效完成後進入可調冷卻期
- 每張搜尋圖片可各自設定 1～20 次提示音與個別試聽；提示音支援 0.25～4 倍速、-40～0 dB 音量及 0～60 秒自訂間隔
- 以「畫面偵測／錄製腳本／播放設定」分頁整理操作介面
- 頂部醒目狀態列同步顯示目前腳本名稱、執行狀態與詳細訊息
- 錄製全域鍵盤事件與精確時間間隔
- 儲存、載入 `.json` 腳本
- 可設定播放次數與速度
- 播放前自動切換至目標視窗
- 播放中若焦點離開目標視窗會自動停止
- 任意時刻按 `F8` 緊急停止錄製或播放

## 執行

需要 Windows 10/11 與 Python 3.10 以上版本。

```powershell
py -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python app.py
```

## 程式結構

- `app.py`：Tkinter 介面、應用程式狀態與各功能流程協調
- `detection.py`：圖片比對、顏色計算與 Windows OCR
- `input_control.py`：鍵盤事件資料、序列化與 Windows 輸入控制
- `audio.py`：提示音參數與 WAV 產生

各模組維持單向依賴，功能核心不會反向匯入 GUI，方便個別測試與後續維護。

某些以系統管理員權限執行的遊戲只能接收同等權限程式送出的按鍵，此時也請用系統管理員身分啟動本工具。部分使用核心層反作弊或獨佔輸入的遊戲可能拒絕模擬輸入；請遵守遊戲服務條款。

## 操作

1. 按「重新整理」，選擇目標視窗。
2. 圖片偵測：可按「匯入圖片」，或按「擷取畫面」後在桌面拖曳框選；完成後可在介面確認範本預覽。再依需要調整相似度門檻。
3. 按「偵測一次」取得即時結果，或按「開始持續偵測」依指定間隔監看。
4. 按「開始錄製」，切到目標視窗輸入操作。
5. 按 `F9` 結束錄製；可儲存腳本，或直接設定次數／速度後播放。

偵測最小化視窗時會先自動還原。部分使用硬體加速、受 DRM 或反作弊保護的視窗可能只會回傳黑畫面，這是目標程式的擷取限制。
